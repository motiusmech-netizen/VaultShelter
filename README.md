# АтомУют: Убежище (AtomHome: Shelter)

Симулятор подземного убежища для **Яндекс Игр** и других HTML5‑порталов.
Строите комнаты в разрезе скалы, распределяете жителей по работам, добываете энергию, еду и воду,
растите семьи, отбиваетесь от напастей, отправляете разведчиков в Пустошь и в финале запускаете
**Проект «Рассвет»**, который оживляет поверхность.

Вся графика, анимации, звуки и музыка генерируются кодом — в сборке нет ни одной картинки
или аудиофайла, только шрифты. Архив для публикации весит около 0,7 МБ.

Полный дизайн‑документ: [`docs/GDD.md`](docs/GDD.md).

## Что внутри

| Область | Где |
| --- | --- |
| Симуляция: ресурсы, комнаты, жители, опыт, семьи, инциденты, Пустошь, задания, крафт, ящики, «Рассвет», офлайн‑прогресс | `src/sim/` |
| Данные: 25 типов комнат, предметы, питомцы, рецепты, миссии, имена, тексты вылазок | `src/data/` |
| Рендер на Canvas 2D: разрез земли, поверхность со сменой дня и ночи, комнаты‑диорамы (3 варианта модулей на каждый тип), персонажи с анимациями, частицы | `src/render/` |
| Интерфейс на Preact в стиле «атомный век»: HUD с приборами, панели, модальные окна, обучение | `src/ui/` |
| Синтезированные звуки и фоновая музыка (Web Audio) | `src/audio/` |
| Обёртка Yandex Games SDK v2: реклама, облачные сохранения, пауза, язык, лидерборд | `src/platform/sdk.ts` |
| Локализация RU / EN | `src/i18n/` |

## Разработка

```bash
npm install
npm run dev          # http://localhost:5173
npm run typecheck
```

Для разработки есть демо‑убежище с 34 жителями: `http://localhost:5173/?demo=1`
(доступно только в dev‑сборке), галерея комнат `dev/gallery.html` и листы персонажей `dev/chars.html`.

## Сборка для Яндекс Игр

```bash
npm run release      # typecheck + vite build + упаковка
```

Результат — `release/atomhome-yandex.zip`, в корне архива лежит `index.html`
(так требует консоль разработчика). Пути относительные, игра работает из любой подпапки.

### Публикация

1. Откройте [консоль разработчика Яндекс Игр](https://yandex.ru/games/console/) и создайте приложение.
2. Во вкладке «Черновик» загрузите `release/atomhome-yandex.zip`.
3. Заполните карточку: название «АтомУют: Убежище», жанр «Симуляторы / Стратегии», возраст 12+,
   языки RU и EN, ориентация «любая», скриншоты и иконку снимите прямо из игры.
4. Включите облачные сохранения (используются `player.getData/setData`) и лидерборд
   с техническим названием `vaultRating`, если хотите таблицу рекордов.
5. Отправьте на модерацию.

### Как выполняются требования платформы

* SDK подключается скриптом `/sdk.js`, после загрузки вызывается `LoadingAPI.ready()`.
* Разметка геймплея: `GameplayAPI.start()` / `stop()` при паузе, открытии меню и рекламы.
* Полноэкранная реклама — не чаще раза в 3 минуты и никогда во время обучения;
  реклама за вознаграждение выдаёт награду только в колбэке `onRewarded`.
* Во время рекламы и при сворачивании вкладки звук и игра ставятся на паузу
  (`game_api_pause` / `game_api_resume`, `visibilitychange`).
* Язык берётся из `environment.i18n.lang`, при необходимости переключается в настройках.
* Прогресс сохраняется в облако и в `localStorage`; при запуске берётся более свежий вариант.
* Нет внешних ссылок, покупок за реальные деньги и чужих товарных знаков.
* Выделение текста, контекстное меню и системные жесты масштабирования отключены.

Без SDK (локально или на другом портале) игра работает автономно: реклама показывается
как короткая заглушка и сразу выдаёт награду, сохранение идёт в `localStorage`.
